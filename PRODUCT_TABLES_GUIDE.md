# Таблиці контенту запчастин Lippert

## Передумови

- Продукт створений і налаштований у PlayCanvas.
- У PlayCanvas заповнений `LippertDefinitions.mjs`: `partNumber` кожної деталі пов’язаний із відповідними 3D-частинами (`entities`).
- Продукт створений і налаштований для відображення у VividBuild; відомий його `variantId`.

## Як додати контент нового продукту

1. **Завантаж шаблон.** Експортуй приклад таблиці [PRODUCT-CONTENT, ID 582](https://build.vivid3d.tech/data_tables/582?organization=9) у форматі `.csv`.

2. **Очисть шаблон.** Видали рядки з контентом попереднього продукту. Збережи всі стовпці, їхні назви та порядок без змін.

3. **Заповни контент нового продукту** за даними клієнта. Один рядок — один унікальний `partNumber`; `id` — послідовний номер рядка. Артикули мають точно збігатися з `partNumber` у PlayCanvas. Відповідність `partNumber` до 3D-об’єктів (`entities`) налаштовується саме у PlayCanvas. Для артикулів із `relatedProducts`, `parentAssemblies` і `components` також додай окремі рядки в цій таблиці.

4. **Створи нову таблицю** в розділі [VividBuild → Data Tables](https://build.vivid3d.tech/data_tables) для нового продукту. Назви таблицю за форматом `PRODUCT-CONTENT_[tableContentId]_[productVariantName]`, наприклад `PRODUCT-CONTENT_582_6000_Spring_Axle`.

5. **Імпортуй підготовлений `.csv`** у створену таблицю та збережи дані.

6. **Скопіюй ID створеної таблиці.** Він знадобиться для поля `tableContentId`.

7. **Додай новий рядок до загальної таблиці [PRODUCTS, ID 576](https://build.vivid3d.tech/data_tables/576?organization=9)** і заповни поля:

   | Поле                 | Значення                                                                                          |
   | -------------------- | ------------------------------------------------------------------------------------------------- |
   | `variantId`          | ID нового продукту у VividBuild. Використовується в адресі продукту в застосунку: `/{variantId}`. |
   | `productVariantName` | Назва варіанту продукту з VividBuild, наприклад `6000_Spring_Axle`.                               |
   | `label`              | Назва продукту для відображення в заголовку застосунку.                                           |
   | `tableContentId`     | ID таблиці контенту, скопійований на кроці 6.                                                     |

   Збережи зміни, не змінюючи рядки інших продуктів.

**Перевір результат:** відкрий продукт у застосунку за адресою `/{variantId}` та перезавантаж сторінку. Перевір підказки наведення й попапи деталей: назви, описи, характеристики, посилання та пов’язані деталі.

## Стовпці таблиці PRODUCT-CONTENT

| Стовпець              | Призначення                                                                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`                  | Порядковий номер рядка в цій таблиці.                                                                                                            |
| `side`                | Сторона деталі, якщо відома. У поточному попапі та підказці не відображається.                                                                   |
| `partNumber`          | Унікальний артикул; ключ зіставлення з 3D-деталлю.                                                                                               |
| `displayName`         | Назва деталі для користувача.                                                                                                                    |
| `groupName`           | Резервна назва, якщо `displayName` порожній; не є ключем зіставлення.                                                                            |
| `category`            | Категорія, що показується бейджем у попапі.                                                                                                      |
| `description`         | Опис деталі в попапі та підказці наведення.                                                                                                      |
| `technical_notes`     | Технічні примітки у попапі.                                                                                                                      |
| `relatedProducts`     | Артикули пов’язаних товарів через кому; у попапі показуються товари з доступним посиланням магазину.                                             |
| `parentAssemblies`    | Артикули батьківських вузлів через кому.                                                                                                         |
| `components`          | Артикули складових деталі або вузла через кому.                                                                                                  |
| `store_link`          | URL магазину. Порожнє значення, `NLA`, `N/A` або `Contact Customer Service for availability` не створюють активного посилання.                   |
| `store_link_text`     | Підпис посилання магазину; без значення використовується `Store Link`. Для звернення до підтримки показується відповідний текст із `store_link`. |
| `spec_material`       | Матеріал.                                                                                                                                        |
| `spec_weight`         | Вага з одиницею вимірювання.                                                                                                                     |
| `spec_torque`         | Момент затягування з одиницею вимірювання.                                                                                                       |
| `spec_bearing_type`   | Тип підшипника.                                                                                                                                  |
| `spec_brake_type`     | Тип гальма.                                                                                                                                      |
| `spec_spring_type`    | Тип пружини або ресори.                                                                                                                          |
| `spec_load_capacity`  | Вантажність з одиницею вимірювання.                                                                                                              |
| `spec_lining_life`    | Ресурс гальмівних накладок.                                                                                                                      |
| `spec_durability`     | Строк служби або ресурс деталі.                                                                                                                  |
| `maint_interval`      | Періодичність обслуговування.                                                                                                                    |
| `maint_task`          | Роботи, які потрібно виконувати під час обслуговування.                                                                                          |
| `maint_common_issues` | Типові несправності або ознаки проблем.                                                                                                          |

Для кожного артикула зі стовпців зв’язків потрібен окремий рядок **у цій самій таблиці продукту**. Наприклад, `122259, 298275` означає два пов’язані артикули. Однаковий артикул у різних продуктах може мати різний контент у їхніх окремих таблицях.
